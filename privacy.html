Privacy policy

Duff Omacal is a personal, single-user desktop widget. This Google OAuth app is operated by its only user, for their own Google account.

What data is accessed

The app requests two Google Calendar scopes: calendar.readonly, to read the list of calendars and the events on them, and calendar.events, to create, edit, and delete events when the user asks it to.

How data is used and stored

Events are fetched every few minutes and written to a file on the user's own computer, only to show them in the desktop bar. Changes are sent straight to the Google Calendar API when the user makes them. OAuth tokens are stored on the same computer, in the user's home folder. There is no server.

Sharing

No data is sent to, shared with, or sold to any third party.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the widget's files removes all local data.
